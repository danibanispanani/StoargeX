# Table View Matrix

## Shared table contract

Each row below defines the required operational projection. All modules use search, ascending/descending sort, filters, column control, row selection, detail drawer, export, and saved user preferences where the action is meaningful. Import appears only where the module supports its mandatory template, dry run, validation, errors, and review/commit flow. Bulk actions are permission- and domain-validated; financial/inventory effects use the established transactional services.
